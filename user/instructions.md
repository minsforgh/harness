# 개인 전역 지시

## 언어

- 사용자에게 보이는 모든 글은 한국어로 쓴다. 답, 보고, 질문 목록(grilling 라운드 포함), 표, 추천, 생각을 드러내는 문장이 모두 해당한다.
- 코드 식별자, 파일 경로, 명령어, 원문 인용만 원문 그대로 둔다.
- 저장소에 남는 글(커밋 메시지, 문서, 코드 주석)의 언어는 프로젝트 규칙을 따른다.
- 길고 구조가 많은 답을 쓸 때 영어로 미끄러지기 쉽다. 내보내기 전에 한국어인지 다시 본다.

## 하네스

- 이 지시와 harness- 플러그인의 원본은 dev-wiki `_harness/`다. 프로젝트 작업 중에는 원본을 고치지 않는다. 고칠 점이 보이면 무엇이 왜 문제인지 사용자에게 보고하고, 고치는 일은 dev-wiki 세션에서 한다.

## dev-wiki 환류

- 프로젝트 세션에서 다음 프로젝트에서도 쓸 지식이 나오면 보고 끝에 `wiki 후보: <한 줄>`을 붙인다. 대상은 공식 문서로 풀리지 않아 직접 원인을 찾은 문제, 여러 선택지 중 하나를 고른 판단과 근거, 실제로 돌려 확인한 패턴이나 설정이다. 일반론, 이 프로젝트에만 맞는 구현, 확인하지 않은 추측은 붙이지 않는다. 한 세션에 한두 번이면 많은 편이다.
- 그 줄은 대화의 보고에만 쓴다. 커밋 메시지, PR, 저장소 문서에는 쓰지 않고 dev-wiki에 직접 기록하지도 않는다. 훅이 이 PC의 대기열에 모으고, 반영은 dev-wiki 세션의 daily-sync에서 사용자가 고른다.
