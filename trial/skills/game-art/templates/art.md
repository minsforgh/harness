# 아트

> 현재 상태 문서. 정식 아트의 화풍, 기준 그림, 만드는 방식. 대상별 지시는 각 그림 폴더의 `prompt_v<판>.md`.

## 화풍

- 한 줄: <예: 애니메이션풍 셀 셰이딩, 굵은 외곽선, 2~3단계 명암>
- 이펙트: <예: 픽셀아트(pixelfx)라 해상도 결이 다르다>
- 움직임: <예: 2D 컷아웃 리그(부위 스프라이트 + Transform 계층 + AnimationClip)>

공통 스타일 줄(모든 프롬프트 끝에 붙인다):

```
Style: <영어 한두 줄>. No text, no logo, no watermark, no frame, no UI.
```

## 만드는 방식

| 무엇 | 값 |
|---|---|
| 생성 | 에이전트가 Codex를 부름 / 사용자가 생성 |
| 모델 | (예: gpt-6.1-sol. 호출마다 `-m`으로 넘긴다) |
| 배경색 | 밝은 회색 단색 |
| 그림 폴더 | `<Art>/<종류>/<이름>/` (지시, 로그, 판별 그림) |
| 도구 폴더 | `<Art>/Tools~/` (cut_solid.py 등) |

|---|---|---|
