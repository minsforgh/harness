# <대상> <무엇> v<판> (YYYY-MM-DD)

너는 게임 컨셉 아트 담당이다. <게임 한 줄 소개>의 <대상>을 이미지 생성 도구로 <N>장 만든다.

## 첨부

- 첫 번째 첨부 `<기준 그림>.png`: 확정 디자인과 화풍. 얼굴, 차림, 색, 선, 채색 방식을 그대로 따른다.
- 두 번째 첨부 `<참고>.png`: <무엇만 참고하는지. 예: 시트 구성과 부위 목록만, 화풍은 따르지 않는다>

## 내용

- <구도, 각도, 자세, 화면에서 놓일 자리>
- <꼭 보여야 할 것: 판정과 맞아야 하는 부위, 규칙을 읽히게 하는 특징>
- 조명은 고르게, 배경은 <프로젝트 배경색> 단색, 배경에 그림자 없음.

## 저장과 보고

- 이 파일이 있는 폴더에 `<이름>_v<판>.png`(안이 여럿이면 `_a`, `_b`)로 저장한다.
- 이 폴더 밖의 파일은 만들거나 고치지 않는다. git 명령은 쓰지 않는다.
- 끝나면 저장한 파일 경로와 결과 요약을 한국어로 세 줄 이내로 보고한다.
