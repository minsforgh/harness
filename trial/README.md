# trial

효과가 입증되지 않은 스킬을 두는 곳. 묶음과 프로필에 넣지 않는다.

- `skills/`: 플러그인 `harness-trial`로 설치되는 시험 스킬. 시험할 프로젝트에서만 local 범위로 켠다(공용 설정 파일에 남지 않음).
  ```
  claude plugin install harness-trial@harness --scope local    # 그 프로젝트 폴더에서
  ```
  고친 뒤 반영은 다른 묶음과 같다(`node _harness/release.mjs harness-trial`).
- `game-ui/`: 묶음에서 뺀 뒤 보관만 하는 옛 스킬(설치되지 않음). 시안 단계는 `skills/game-mockup`이 이어받았다.

## 통과 기준

시험 기록이 3번 쌓이면 아래로 판정한다. 통과하면 묶음(unity 또는 core)으로 옮기고, 아니면 고치거나 버린다.

| 스킬 | 제때 불렸나 | 단계를 따랐나 | 무엇을 잡았거나 줄였나 | 비용 |
|---|---|---|---|---|
| game-art | "그림 뽑자", "정식 아트"에 사용자가 스킬 이름을 말하지 않아도 불림 | 지시 파일과 판 번호를 남김, 기준 그림을 참고로 첨부, 움직일 캐릭터는 조립 그림 기준 | 다시 뽑기 횟수, 화풍이 어긋난 판, 관절 어긋남을 스킬 없이 했을 때보다 줄임 | 사용자가 그림 하나를 고르기까지 주고받은 횟수 |
| game-mockup | 화면 질문이 나왔을 때 불림. 사용자가 모양을 말로 다 정했을 때는 불리지 않음 | 질문 한 줄, 상태 버튼과 자리 설명, 확정을 설계 문서로 옮김 | 시안 덕에 구현 전에 바뀐 결정, 구현 뒤 캡처 비교에서 잡은 차이 | 시안을 만들고 고친 횟수와 시간 |
