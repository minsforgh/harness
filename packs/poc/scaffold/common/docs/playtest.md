# 플레이테스트와 설계 기록

> 기록 문서. 끝에 더하기만 하고 지난 기록은 고치지 않는다. 항목마다 날짜가 붙은 제목을 단다.
>
> - `## YYYY-MM-DD 플레이테스트`: 누가 했나, 체크리스트 결과, 관찰한 행동과 의견(나눠서, 다르면 행동을 믿는다), 질문별로 알게 된 것, 바꾼 수치(TuningConfig 필드와 전후 값), 결론(계속, 피벗, 중단)
> - `## YYYY-MM-DD 설계 기록`: 구현과 플레이 중에 나온 기획 쪽 발견 한 줄씩
> - `## YYYY-MM-DD 설계 회고`: 마감 때. 장르, 독창성, 명료성, 깊이, 재미, 제작(비쌌던 것과 쌌던 것), 기획 문서와 비교(맞은 것과 틀린 것), 다음 아이디어에 가져갈 것
